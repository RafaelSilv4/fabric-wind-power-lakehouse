# Power BI

Esta pasta contém todos os artefatos relacionados ao desenvolvimento do relatório analítico do projeto **Fabric Wind Power Lakehouse**.

---

## Estrutura

### 📊 Dashboards

Contém o relatório desenvolvido no Power BI Desktop e capturas de tela das páginas do dashboard.

---

### 📐 Modelo Semântico

Contém imagens e documentação do modelo dimensional utilizado no projeto.

Principais tabelas:

- fact_wind_power
- dim_turbine
- dim_location

---


## Tecnologias utilizadas

- Microsoft Fabric
- Power BI Desktop
- DAX
- Power Query
- Modelo Estrela
- Semantic Model

---

## Objetivo

Disponibilizar um dashboard analítico construído sobre a camada Gold do Lakehouse, utilizando um modelo dimensional otimizado para análise e visualização dos dados.
